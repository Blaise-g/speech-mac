# Historical records

This committed tracker retains its original directory name, ticket identifiers and execution records. They document earlier implementations and the current Phonon runtime; historical names and measurements do not describe supported commands or current model performance.

Ticket37 removed obsolete model results and superseded design documents from the maintained checkout. Their original bytes remain in the [pre-cleanup Git snapshot](https://github.com/Blaise-g/speech-mac/tree/3434f73aeada7e1818feb11cf4815b773a21188b). Historical Markdown links into those removed files now point to that immutable commit. The archived [streaming design](https://github.com/Blaise-g/speech-mac/blob/3434f73aeada7e1818feb11cf4815b773a21188b/docs/streaming-plan.md), [initial inference decision](https://github.com/Blaise-g/speech-mac/blob/3434f73aeada7e1818feb11cf4815b773a21188b/docs/adr/0001-native-inference.md), [old model results](https://github.com/Blaise-g/speech-mac/tree/3434f73aeada7e1818feb11cf4815b773a21188b/artifacts), and [provider setup record](https://github.com/Blaise-g/speech-mac/blob/3434f73aeada7e1818feb11cf4815b773a21188b/docs/remote-setup.md) preserve their original context.

Current Phonon artifacts from tickets32 through35, fixture/pin/budget/lock files and third-party notices are retained unchanged. Their raw records may contain the original absolute checkout paths or repository names. Those values identify the actual runs and must not be relabelled. Negative tests name forbidden files and symbols to prevent their reintroduction. Ignored local models, voices, build caches, user backups and external installed commands are outside tracked cleanup.

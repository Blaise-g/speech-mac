# English normalization differential corpus

`fixtures.jsonl` records representative and held-out inputs with expected outputs generated by the pinned oracle in `../normalization-oracle`. It covers character handling, Unicode, all seven default rewrite rules, overlaps, boundaries, near misses, slash units, and punctuation. Input validity checks for malformed UTF-8, embedded NUL, and unsupported languages are separate native API tests in `tests/test_english_normalize.c`.

Run the reproducible differential check from the repository root:

```sh
UV_CACHE_DIR=/private/tmp/speech-mac-uv-cache uv run --project reference/phonon --offline --no-sync --locked python reference/phonon/normalization/compare.py
```

The script runs the pinned Rust oracle and the native C probe on every fixture, then checks both against the checked-in expected output. The oracle is a development tool only.
